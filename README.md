# 🏥 Smart Hospital Appointment Scheduling System

A Flask and MySQL based hospital appointment management system that helps streamline patient scheduling, queue management, wait-time prediction, and doctor workflow.

## ✨ Features

- 📅 Appointment Booking
- 👤 Patient Management
- 🤖 AI-Based Consultation Time Prediction
- 🚦 Priority Queue Management
- ⏳ Wait Time Estimation
- 👨‍⚕️ Doctor Dashboard
- 🔔 Patient Notifications
- 🚨 Emergency Appointment Handling
- 📊 Doctor Utilization Analytics

## 🛠 Tech Stack

- Python (Flask)
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 Run Project

```bash
pip install flask flask-mysqldb flask-cors
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
